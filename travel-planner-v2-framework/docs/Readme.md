# 文档目录说明

本目录是团队唯一的文档集。**契约与指南保持最新；交付/验收记录是历史快照，不要据此判断当前实现。**

## 根目录 —— 长期维护，需保持最新

| 文件                          | 用途                                    |
| ----------------------------- | --------------------------------------- |
| `接口与数据约定.md`           | 唯一接口契约（v1.2），A/B/C/D 共同维护  |
| `联调与验收说明.md`           | 联调规则、交接顺序、验收流程            |
| `随心行-前端接入说明.md`      | 前端与外壳（React 视频前端）的接入方式  |
| `随心行-C模块接口联调约定.md` | C 与 B 的接口接线（`/api/b`、令牌复用） |
| `当前分工与联调交付.md`       | 当前分工与已交付能力概览                |
| `Readme.md`                   | 本说明                                  |

## 维护约定

1. 契约变更只改 `接口与数据约定.md`，同步更新示例与共享类型。
2. 新增文档放入对应子目录；历史文档不再改内容，只归档。
3. 合并或移动文档时，同步更新链接与根 README。
4. `examples/` 路径被代码硬编码引用，不要移动或改名。
